# 시작하기

AI 기반 개인 이메일 비서인 **Email Automator**에 오신 것을 환영합니다. 이 가이드는 **"Bring Your Own Key" (BYOK)** 모델을 사용하여 애플리케이션을 설정하는 방법을 도와줍니다. 이 모델은 귀하의 데이터가 귀하의 고유한 Supabase 인프라 내에서 제어되도록 보장합니다.

## 🛠 사전 요구 사항

시작하기 전에 다음 사항을 확인하십시오.

1.  **RealTimeX Desktop**: 설치 및 실행 중이어야 합니다. 이는 AI 처리(LLM) 및 텍스트 음성 변환(TTS) 기능에 필요합니다.
2.  **Supabase 계정**: [supabase.com](https://supabase.com)의 무료 또는 유료 계정.

---

## 🚀 설정 마법사를 통한 빠른 설정

내장된 **설정 마법사(Setup Wizard)**는 권장되는 시작 방법입니다. 기술적인 복잡한 작업을 자동화해 줍니다.

### 1. 구매 및 실행
*   **RealTimeX Desktop**을 엽니다.
*   **Marketplace** 탭 → **Local Apps**로 이동합니다.
*   **"Email Automator"**를 검색하여 구매합니다(이미 소유한 경우 활성화).
*   구매가 완료되면 로컬 앱 목록에서 **Launch**(실행)를 클릭합니다.

### 2. 설정 마법사 실행
처음 실행하면 앱이 초기 구성을 안내합니다.

*   **설정 경로 선택**:
    *   **관리형 프로비저닝(권장)**: **Supabase 액세스 토큰**을 제공합니다. 마법사가 자동으로 새 프로젝트를 생성하고, 데이터베이스 마이그레이션을 실행하며, Edge Functions를 배포하고, 초기 지식 베이스를 수집합니다.
    *   **기존 프로젝트 연결**: **프로젝트 URL**과 **Anon Key**를 제공하여 기존 Supabase 프로젝트를 사용합니다. 선택적으로 액세스 토큰을 제공하여 마법사가 마이그레이션을 대신 실행하게 할 수도 있습니다.

### 3. 계정 생성
데이터베이스가 준비되면 로컬 사용자 계정을 생성하고 로그인하여 **대시보드**에 액세스하라는 메시지가 표시됩니다.

---

## 🔍 Supabase 자격 증명 찾기

기존 프로젝트를 수동으로 연결하기로 선택한 경우, [Supabase 대시보드](https://supabase.com/dashboard)에서 자격 증명을 찾을 수 있습니다.

1.  프로젝트를 선택합니다.
2.  **Settings**(설정) → **API**로 이동합니다.
3.  **Project URL**: "Project URL" 아래에 있는 URL을 복사합니다.
4.  **API Key**: "Project API keys" 아래에 있는 **anon (public)** 키를 복사합니다.

> [!WARNING]
> **보안 주의**: `service_role` 키를 절대 사용하지 마십시오. 이 키는 완전한 관리자 우회 권한을 가지고 있으며 클라이언트 측 애플리케이션에서 노출되어서는 안 됩니다.

---

## 🪪 액세스 토큰 생성

액세스 토큰을 사용하면 설정 마법사가 귀하를 대신하여 Supabase 프로젝트(생성, 마이그레이션, 기능 배포)를 관리할 수 있습니다.

1.  Supabase 대시보드에서 **Account**(계정) → **Access Tokens**(액세스 토큰)으로 이동합니다.
2.  **Generate new token**을 클릭하고 이름(예: "Email Automator")을 입력한 후 결과를 복사합니다.
3.  메시지가 표시되면 이 토큰을 설정 마법사에 붙여넣습니다.
