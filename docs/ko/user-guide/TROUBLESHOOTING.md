# 문제 해결 및 지원

문제가 발생한 경우 이 가이드에서 가장 일반적인 함정과 해결 방법을 다룹니다.

---

## 📡 동기화 문제

### 대시보드에 이메일이 나타나지 않음
*   **"Sync From" 날짜 확인**: AI는 이 날짜 *이후*에 수신된 이메일만 처리합니다.
*   **검사점 재설정(Reset Checkpoint)**: 시작 날짜를 변경하고 이전 이메일을 다시 검사하려면 동기화 범위 패널에서 **Reset Checkpoint** 버튼을 클릭하세요.
*   **배치 제한**: **Max Emails** 설정은 실행당 처리되는 이메일 수를 제한합니다. 백로그가 많은 경우 따라잡는 데 여러 번의 동기화 주기가 걸릴 수 있습니다.
*   **수동 트리거**: 대시보드에서 **Run Sync Now**를 클릭하여 즉시 확인을 강제합니다.

### "Sync Failed" 또는 "Backend Not Connected"
*   **로컬 서버**: Email Automator 애플리케이션이 열려 있고 실행 중인지 확인하세요.
*   **실시간 활동 피드**: **Live Activity** 터미널을 엽니다. 여기에는 종종 구체적인 기술적 오류 메시지(예: "Network Error" 또는 "401 Unauthorized")가 포함되어 있습니다.

## 🔑 인증 및 권한

### Google/Gmail: `redirect_uri_mismatch`
*   **해결 방법**: Google Cloud Console의 리디렉션 URI가 Email Automator에 표시된 것과 *정확히* 일치해야 합니다.
*   **예**: `https://your-ref.supabase.co/functions/v1/auth-gmail/callback` (후행 슬래시나 공백이 없는지 확인하세요).

### Microsoft/Outlook: 로그인 실패 또는 시간 초과
*   **앱 등록**: Azure 앱 등록에서 "공용 클라이언트 흐름 허용"이 **예**로 설정되어 있는지 확인하세요.
*   **계정 유형**: 등록 시 "모든 조직 디렉터리의 계정 및 개인 Microsoft 계정"을 선택했는지 확인하세요.

### Supabase: "Invalid API Key"
*   **해결 방법**: 항상 **anon (public)** 키를 사용하세요. **service_role** 키는 보안상의 이유로 앱에서 거부됩니다.

## 🤖 AI 및 RealTimeX 통합

### AI가 느리거나 응답하지 않음
*   **로컬 모델**: Ollama 또는 LM Studio를 사용하는 경우 컴퓨터에 충분한 RAM이 있고 GPU 부하가 너무 크지 않은지 확인하세요.
*   **검색**: 드롭다운에 모델이 나타나지 않으면 **RealTimeX Desktop**이 실행 중인지, 그 안에 하나 이상의 AI 제공업체가 구성되어 있는지 확인하세요.

### "스마트 초안"이 생성되지 않음
*   **시스템 토글**: Auto-Pilot 탭에서 **Smart Drafts**가 **ON**으로 설정되어 있는지 확인하세요.
*   **규칙 충돌**: 이메일과 일치하는 규칙에 실제로 **Draft**(초안) 작업이 포함되어 있는지 확인하세요.
*   **안전 필터**: AI는 "봇 루프"를 방지하기 위해 `no-reply` 주소 및 특정 자동 알림에 대한 초안 작성을 자동으로 건너뜁니다.

## 🗄️ 데이터베이스 및 마이그레이션

### "데이터베이스 마이그레이션 필요" 배너
*   **발생 원인**: 로컬 앱이 업데이트되어 새 기능을 지원하기 위해 Supabase 데이터베이스 스키마를 업데이트해야 합니다.
*   **해결 방법**: 배너에서 **Update Now**를 클릭하세요. 자동 업데이트를 실행하려면 **Supabase 액세스 토큰**이 필요합니다.

### 실시간 터미널이 비어 있거나 "404"가 표시됨
*   **실시간 권한**: 최신 마이그레이션을 실행했는지 확인하세요. `processing_events` 테이블이 존재하고 올바른 RLS(행 레벨 보안) 정책이 활성화되어 있어야 합니다.

---

## 🆘 여전히 도움이 필요하신가요?

문제가 여기에 나열되어 있지 않은 경우:
1.  기술 스택 추적을 확인하려면 계정 설정에서 **시스템 로그(System Logs)**를 확인하세요.
2.  고급 설정 세부 정보는 [개발자 문서](../docs-dev/README.md)를 검토하세요.
3.  프로젝트 저장소에서 티켓을 생성하거나 토론을 시작하세요.
