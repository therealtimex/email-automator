# RealTimeX Marketplace 목록: Email Automator

## 메타데이터
- **표시 이름**: Email Automator
- **짧은 설명**: 편지함 관리 방법을 학습하는 에이전트 기반의 AI 구동 이메일 관리 플랫폼입니다. 클라우드 비용 없이 완전한 개인정보 보호와 함께 "귀하의 편지함을 소유"하세요.
- **태그**: 생산성, 이메일, 자동화, AI 에이전트, 개인정보 보호

---

## 상세 설명

### 📧 귀하의 편지함을 소유하세요
**Email Automator**는 귀하의 개인 이메일 집사입니다. 단순히 스팸을 필터링하는 것이 아니라, 귀하의 편지함을 관리해야 할 작업 목록으로 처리합니다. 로컬 AI를 활용하여 데이터가 귀하의 통제를 벗어나지 않고도 이메일을 분류하고, 우선순위를 지정하고, 답장 초안을 작성합니다.

### 🚀 주요 기능

-   **스마트 카테고리 분류**: AI가 시각적 헤더와 콘텐츠 분석을 기반으로 수신 이메일을 카테고리(뉴스레터, 거래, 소셜 등) 및 우선순위(높음, 중간, 낮음)로 자동 분류합니다.
-   **인박스 제로(Inbox Zero) 엔진**: "7일 후 뉴스레터 보관" 또는 "스팸 즉시 삭제"와 같은 자동화 규칙을 정의하세요. 엔진은 백그라운드에서 지칠 줄 모르고 작동하여 편지함을 깨끗하게 유지합니다.
-   **문맥 인식 에이전트**: 편지함과 대화하세요. **에이전트**를 사용하여 음성으로 초안을 검토("내 초안 읽어줘", "이거 보내줘")하거나, 구성 도움말을 요청하거나, 복잡한 규칙에 대한 설명을 들을 수 있습니다.
-   **승리하는 답변(Winning Responses)**: 중요한 이메일의 경우, 오토파일럿이 귀하의 톤과 의도를 포착하여 사전 작성된 "승리하는 답변" 초안을 생성하며, 귀하의 승인만 받으면 즉시 전송될 수 있습니다.
-   **실시간 터미널**: AI가 생각하는 과정을 지켜보세요. 내장된 실시간 터미널은 에이전트가 무엇을 분석하고, 결정하고, 수행하는지 실시간으로 정확하게 보여줍니다.

### 🛡️ 개인정보 보호 우선: 귀하의 데이터, 귀하의 인프라
**"귀하의 데이터를 소유하세요"**라는 철학을 바탕으로 구축되었습니다.
-   **제로 클라우드 비용**: 귀하의 무료 티어 Supabase 인스턴스와 로컬 시스템에서 전적으로 실행됩니다.
-   **로컬 AI**: **RealTimeX SDK**를 사용하여 로컬 모델(또는 API 키)에 안전하게 연결합니다. 특정 공급업체에 종속되지 않습니다.

### 🔌 원활한 통합
**RealTimeX Desktop**과 함께 실행되도록 설계되었습니다. 로컬 AI 제공업체를 자동으로 감지하고 RealTimeX 생태계를 통해 동기화합니다.
