# Documentation Email Automator

Bienvenue dans la documentation d'**Email Automator**, votre assistant e-mail personnel alimenté par l'IA. Cet outil fonctionne localement sur votre machine, garantissant la confidentialité de vos données tout en exploitant la puissance de l'IA pour organiser, prioriser et automatiser votre boîte de réception.

## 🚀 Fonctionnalités clés

*   **Confidentialité d'abord** : Vos e-mails ne touchent jamais nos serveurs. Le traitement est local ou via vos propres clés IA.
*   **Analyse intelligente** : Catégorisation automatique, analyse de sentiment et résumé.
*   **IA "Boîte de Verre"** : Transparence totale via le Terminal en direct et les modaux Trace IA.
*   **Auto-Pilot** : Gestion centralisée pour les règles "If This Then That" pilotées par l'IA.
*   **Retour multi-sensoriel** : Indices audio et haptiques de haute qualité pour l'activité en arrière-plan.
